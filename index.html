Nothing on this page is real. The directories, the tools, the counts and the 38,000 founders come from a random number generator. There's no checkout and no mailing list, and the newsletter box forgets you the moment you press Subscribe. Every directory is a permalink, so the same link always builds the same one.


  

    
Why this exists

    
I made this because every indie hacker builds a SaaS directory eventually, usually right after the SaaS. I almost built one too. Then I figured the button that makes them was the funnier product, and it never asks me to approve anybody's listing.

    
The badge is a real SVG. Put it on your site if you want. It links back here, and the small print says the directory doesn't exist. I checked and that part is true.

    
What I actually use is merge.tel. It turns my merged pull requests into posts about what changed. This repo merges one every morning to make the day's directory, which is more shipping than I did most of last year.
